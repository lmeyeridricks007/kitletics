# Product Review Agent — Evidence & Synthesis

## Source priority

### Factual

1. Official manufacturer product page  
2. Official documentation / PDF / manual  
3. Official brand announcements  
4. Authorized retailer (when needed)

### Subjective performance

1. Kitletics first-hand (`personal-test`)  
2. High-quality independent specialist reviews  
3. Reputable lab / testing sources  
4. Other credible specialist coverage  

Do not use low-quality affiliate SEO sites as primary evidence.

## Manufacturer limitation

May establish: specs, construction, features, technology, fit/size options, compatibility, dimensions.

Must **not** independently establish: comfort, durability, performance superiority, value, ride feel, maneuverability, real-world battery, etc.

## Conflicts

If sources disagree, create/record a SourceConflict. Synthesize honestly (“feedback is mixed…”) — never silently pick a side.

## Claim provenance

Every substantive claim must be internally traceable to Evidence IDs. Public UI does not need per-sentence citations.

## Synthesis checklist

- Title: `[Brand] [Product] Review`  
- Short verdict: 2–4 sentences (what / strongest / who / trade-off)  
- Pros: 3–5 specific; reject “comfortable”, “great performance” without reason  
- Compromises: 2–4 only when evidence supports — do not invent for UI symmetry  
- Best For / Not Ideal: from recommendation contexts + design — Not Ideal is not mere inverse  
- Sections: category-appropriate depth  
- Alternatives: 2–4 from relationship graph with reasons  
- Methodology: Expert Research approved copy when applicable
