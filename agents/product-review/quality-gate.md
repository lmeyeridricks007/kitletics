# Product Review Agent — Quality Gate

Template: Nike Vomero 18 — see [`page-standard.md`](./page-standard.md).

Before proposing publish (human step), verify:

- [ ] Valid Product identity + authentic media  
- [ ] Review type correct (no fake first-hand)  
- [ ] Short verdict + full verdict (not duplicates)  
- [ ] Pros specific (3–5)  
- [ ] Compromises contextual when supported  
- [ ] **Buy if / Skip if** are detailed decision lines (≥2–3 each) — not labels  
- [ ] Substantive sections for category (fit/cushioning/ride/… depth for shoes)  
- [ ] Evidence linked; independent sources for major Expert Research  
- [ ] Alternatives / comparisons / guides connected where available  
- [ ] Brand/product peers named so linkify can resolve  
- [ ] Section images unique + product-only for **every major section** (generate from hero if missing; never leave Key specs / Tracking / Performance empty when a hero exists)  
- [ ] No internal terminology in public fields  
- [ ] No mutable prices in prose  
- [ ] `canPublishReview` returns ok  
- [ ] Editorial locks respected on refresh  
- [ ] No `isReportOrJunkVoice` hits on section bodies  

Internal ReviewReadiness is for agents/editors only.
