# HYROX Recommendation Methodology

## Contexts

- `uc-hyrox-race` / `hyrox-race`
- `uc-hyrox-training` / `hyrox-training`
- Supporting: beginner, home-training, conditioning

## Shoe factors (evidence-backed only)

| Factor | Inputs | Missing data |
| --- | --- | --- |
| Running suitability | category, weight, cushion specs, rec scores | lower confidence; do not invent |
| Stability | platform / hyroxSuitability / training category | prefer qualitative labels |
| Traction | outsole notes when verified | omit fake “sled score” |
| Versatility | dual use training+run | — |

**Do not invent** numeric “Sled Push Score: 94”. Prefer Strong / Good with explanation when evidence exists.

## Neutrality

- Marketing “Made for HYROX” does not raise score
- Official partnerships are metadata only
- Affiliate commission never enters ranking

## Match vs Score

- **Kitletics Score** — category product assessment
- **Kitletics Match** — fit to Finder answers
